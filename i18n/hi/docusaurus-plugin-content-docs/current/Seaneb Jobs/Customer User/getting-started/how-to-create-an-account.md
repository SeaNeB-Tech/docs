# खाता कैसे बनाएं

सीनेब जॉब्स पर खाता बनाना बेहद सरल है। इसमें कोई जटिल पासवर्ड याद रखने की जरूरत नहीं होती।


![सीनेब जॉब्स मोबाइल लॉगिन स्क्रीन](/img/web/login.png)


![प्रोफ़ाइल पूर्णता और खाता पंजीकरण](/img/web/create-account.png)


### आवश्यक आवश्यकताएं
- 10 अंकों का सक्रिय भारतीय मोबाइल नंबर।
- इंटरनेट कनेक्शन युक्त फोन या कंप्यूटर।
- बुनियादी व्यक्तिगत जानकारी।

### आवश्यक शर्तें
- एक सक्रिय सीनेब जॉब्स खाता।
- आपके फोन या कंप्यूटर पर एक स्थिर इंटरनेट कनेक्शन।

### मोबाइल ऐप अनुभव

![मोबाइल दृश्य - पंजीकरण और खाता निर्माण स्क्रीन](/img/mobile/create-acccount.png)

### चरण-दर-चरण निर्देश
1. वेबसाइट https://jobs.seaneb.com/ पर जाएं।
2. "लॉगिन / साइन अप" बटन पर क्लिक करें।
3. अपना मोबाइल नंबर दर्ज करें और "ओटीपी भेजें" दबाएं।
4. प्राप्त 6 अंकों का ओटीपी दर्ज करें।
5. अपना पूरा नाम और शहर चुनकर सबमिट करें।

### अपेक्षित परिणाम
आपका खाता तुरंत सक्रिय हो जाएगा और आप अपने डैशबोर्ड पर पहुंच जाएंगे।

### सामान्य समस्याएं और समाधान
| समस्या | समाधान |
| :--- | :--- |
| **ओटीपी नहीं आया** | टाइमर समाप्त होने के बाद "ओटीपी पुनः भेजें" पर क्लिक करें। |

### उपयोगी सुझाव
> **सुझाव:** हमेशा अपना सक्रिय नंबर दर्ज करें ताकि नियोक्ता आपसे फोन पर बात कर सकें।
