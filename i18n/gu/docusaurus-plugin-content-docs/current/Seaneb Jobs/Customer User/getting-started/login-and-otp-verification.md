# લૉગિન અને ઓટીપી વેરિફિકેશન

સીનેબ જોબ્સ સુરક્ષિત મોબાઇલ ઓટીપી સિસ્ટમ વાપરે છે જેથી તમારું એકાઉન્ટ હંમેશા સુરક્ષિત રહે.


![સીનેબ જોબ્સ મોબાઇલ લૉગિન સ્ક્રીન](/img/web/login.png)


![ઓટીપી વેરિફિકેશન સ્ક્રીન](/img/web/otp.png)


### સુરક્ષા માહિતી
- ઓટીપી ફક્ત 10 મિનિટ માટે માન્ય છે.
- તમારો ઓટીપી કોઈની સાથે શેર કરશો નહીં. સીનેબ ટીમ ક્યારેય ઓટીપી માંગતી નથી.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. હોમપેજ પર "લૉગિન" બટન દબાવો.
2. તમારો 10 અંકનો મોબાઇલ નંબર દાખલ કરો.
3. એસએમએસ કે વોટ્સએપ પર આવેલો 6 અંકનો કોડ દાખલ કરો.
4. વેરિફિકેશન પૂર્ણ થતાં તમે લૉગિન થઈ જશો.

### અપેક્ષિત પરિણામો
તમારું લૉગિન સત્ર સુરક્ષિત રીતે શરૂ થઈ જશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **ખોટો કોડ** | ખાતરી કરો કે તમે સૌથી છેલ્લો આવેલો કોડ દાખલ કર્યો છે. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** તમારા ફોન પર લૉગિન ચાલુ રાખો જેથી નોકરીની સૂચનાઓ તુરંત મળે.
