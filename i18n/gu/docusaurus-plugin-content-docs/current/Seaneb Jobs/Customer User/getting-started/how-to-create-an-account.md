# એકાઉન્ટ કેવી રીતે બનાવવું

સીનેબ જોબ્સ પર એકાઉન્ટ બનાવવું ખૂબ જ સરળ છે. તેમાં કોઈ પાસવર્ડ યાદ રાખવાની જરૂર નથી.


![સીનેબ જોબ્સ મોબાઇલ લૉગિન સ્ક્રીન](/img/web/login.png)


![પ્રોફાઇલ પૂર્ણતા અને એકાઉન્ટ નોંધણી](/img/web/create-account.png)


### જરૂરી બાબતો
- 10 અંકનો સક્રિય ભારતીય મોબાઇલ નંબર.
- ઇન્ટરનેટ કનેક્શન ધરાવતો ફોન અથવા કમ્પ્યુટર.
- મૂળભૂત વ્યક્તિગત માહિતી.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. વેબસાઇટ https://jobs.seaneb.com/ પર જાઓ.
2. "લૉગિન / સાઇન અપ" બટન પર ક્લિક કરો.
3. મોબાઇલ નંબર દાખલ કરો અને "ઓટીપી મોકલો" દબાવો.
4. આવેલો 6 અંકનો ઓટીપી દાખલ કરો.
5. પૂરું નામ અને શહેર પસંદ કરીને સબમિટ કરો.

### અપેક્ષિત પરિણામો
તમારું એકાઉન્ટ તરત જ સક્રિય થશે અને તમે ડેશબોર્ડ પર પહોંચી જશો.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **ઓટીપી આવ્યો નથી** | સમય સમાપ્ત થયા પછી "ઓટીપી ફરી મોકલો" પર ક્લિક કરો. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** હંમેશા સક્રિય નંબર વાપરો જેથી નોકરીદાતા તમારો સીધો સંપર્ક કરી શકે.
