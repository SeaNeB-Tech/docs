# નોકરી શોધનારાઓ માટે એકાઉન્ટ સેટિંગ્સ

એકાઉન્ટ સેટિંગ્સ દ્વારા તમે તમારી ગોપનીયતા, સૂચનાઓ અને નોકરી શોધની સ્થિતિ નિયંત્રિત કરી શકો છો.


![નોકરી શોધનારાઓ માટે એકાઉન્ટ સેટિંગ્સ](/img/web/Settings.png)


### મુખ્ય સેટિંગ્સ
- **નોકરી શોધ સ્થિતિ:** ચાલુ હોય ત્યારે નોકરીદાતાઓ તમને શોધી શકે છે.
- **સૂચનાઓ:** એસએમએસ, ઈમેલ અને વોટ્સએપ એલર્ટ મેનેજ કરો.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. પ્રોફાઇલ મેનૂમાંથી "સેટિંગ્સ" ખોલો.
2. ઇચ્છિત વિકલ્પ પસંદ કરો.
3. ફેરફાર કરો અને "સેવ" પર ક્લિક કરો.

### અપેક્ષિત પરિણામો
તમારી નવી પસંદગીઓ તરત જ લાગુ થશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **એલર્ટ બંધ થતા નથી** | ખાતરી કરો કે તમે ફેરફાર કર્યા પછી "સેવ" દબાવ્યું છે. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** જો નોકરી મળી જાય, તો એકાઉન્ટ ડિલીટ કરવાને બદલે શોધ સ્થિતિ "બંધ" કરો.
