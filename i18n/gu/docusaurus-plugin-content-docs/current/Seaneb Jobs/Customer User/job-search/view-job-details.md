# નોકરીની વિગતો જુઓ

અરજી કરતા પહેલા નોકરીના નિયમો, જવાબદારીઓ, પગાર અને કાર્યસ્થળની સંપૂર્ણ માહિતી મેળવો.


![નોકરીની સંપૂર્ણ વિગતો અને લાયકાત](/img/web/job-details.png)


### શું તપાસવું
- **કાર્ય અને જવાબદારીઓ:** દૈનિક કામ અને શિફ્ટનો સમય.
- **પગાર અને લાભો:** ફિક્સ પગાર, ઇન્સેન્ટિવ, પીએફ.
- **સ્થળ:** કાર્યસ્થળનું ચોક્કસ સરનામું.
- **ચકાસાયેલ બેજ:** સીનેબ દ્વારા વેરિફાઇ થયેલ નોકરીદાતાનું ચિહ્ન.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. કોઈપણ નોકરી કાર્ડ પર ક્લિક કરો.
2. કામની વિગતો અને જવાબદારીઓ ધ્યાનથી વાંચો.
3. તપાસો કે તમે લાયકાત પૂરી કરો છો.
4. "હમણાં અરજી કરો" અથવા "સાચવો" પસંદ કરો.

### અપેક્ષિત પરિણામો
તમને પદ વિશે સંપૂર્ણ સ્પષ્ટતા મળી જશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **શંકાસ્પદ વિગત** | પેજના તળિયે "નોકરીની જાણ કરો" પર ક્લિક કરો. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** આવવા-જવાનું અંતર ચકાસો જેથી દૈનિક મુસાફરી અનુકૂળ રહે.
