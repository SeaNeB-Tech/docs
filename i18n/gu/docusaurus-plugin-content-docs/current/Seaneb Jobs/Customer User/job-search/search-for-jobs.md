# નોકરીઓ શોધો

સીનેબ જોબ્સના સર્ચ એન્જિનથી તમે તમારા મનપસંદ હોદ્દા, કૌશલ્ય કે વિસ્તાર મુજબ નોકરીઓ શોધી શકો છો.


![હોમપેજ પર જોબ સર્ચ બાર](/img/web/home.png)


![શહેરમાં ઉપલબ્ધ નોકરીઓની યાદી](/img/web/job-list.png)


### શોધવાની રીતો
- **હોદ્દા મુજબ:** જેમ કે એકાઉન્ટન્ટ, ડ્રાઈવર, સેલ્સ, રસોઈયા વગેરે.
- **સ્થાન મુજબ:** તમારા શહેર અથવા પિન કોડ દ્વારા શોધો.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. હોમપેજ પર સર્ચ બારમાં હોદ્દો કે આવડત લખો.
2. તમારું શહેર પસંદ કરો.
3. "નોકરીઓ શોધો" બટન દબાવો.
4. પરિણામોની યાદી જુઓ.

### અપેક્ષિત પરિણામો
તમારી પસંદગી મુજબની નોકરીઓની યાદી સામે આવી જશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **ઓછી નોકરીઓ દેખાય છે** | સર્ચ શબ્દ સામાન્ય બનાવો અથવા વિસ્તારની મર્યાદા વધારો. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** દરરોજ સર્ચ કરો કારણ કે સ્થાનિક નોકરીદાતાઓ રોજેરોજ નવી નોકરીઓ મૂકે છે.
