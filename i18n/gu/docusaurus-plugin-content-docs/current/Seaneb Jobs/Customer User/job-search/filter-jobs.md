# નોકરીઓ ફિલ્ટર કરો

ફિલ્ટર્સની મદદથી તમે પગાર, અનુભવ, અંતર અને કાર્ય પ્રકાર અનુસાર સૌથી યોગ્ય નોકરીઓ પસંદ કરી શકો છો.


![જોબ સર્ચ ફિલ્ટર્સ (પગાર, કાર્ય મોડ, અનુભવ)](/img/web/job-list.png)


### ઉપલબ્ધ ફિલ્ટર્સ
- **પગાર મર્યાદા:** તમારી અપેક્ષિત માસિક આવક.
- **અનુભવ:** ફ્રેશર અથવા જરૂરી અનુભવના વર્ષો.
- **અંતર:** તમારા ઘરથી 5 કિમી, 10 કિમી કે આખા શહેરમાં.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. સર્ચ પરિણામ પેજ પર "ફિલ્ટર" પર ક્લિક કરો.
2. પગાર, અનુભવ કે નોકરીનો પ્રકાર પસંદ કરો.
3. "ફિલ્ટર લાગુ કરો" પર ક્લિક કરો.

### અપેક્ષિત પરિણામો
માત્ર તમારી પસંદગી મુજબની નોકરીઓ જ દેખાશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **કોઈ પરિણામ મળ્યું નહીં** | એકાદ કડક ફિલ્ટર હટાવીને ફરીથી પ્રયાસ કરો. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** શરૂઆતમાં ઓછા ફિલ્ટર લગાવો જેથી સારો વિકલ્પ ચૂકી ન જવાય.
