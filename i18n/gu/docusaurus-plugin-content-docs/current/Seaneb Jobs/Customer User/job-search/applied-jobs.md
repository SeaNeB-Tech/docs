# અરજી કરેલી નોકરીઓ

તમારી અગાઉની તમામ અરજીઓની સ્થિતિ અને પ્રગતિ એક જ ડેશબોર્ડ પર ટ્રૅક કરો.


![મારી નોકરીની અરજીઓ અને સ્થિતિ](/img/web/applications.png)


### અરજીની સ્થિતિઓ
- **મોકલેલ:** નોકરીદાતાને તમારી અરજી મળી ગઈ છે.
- **જોયેલ:** નોકરીદાતાએ તમારો બાયોડેટા જોઈ લીધો છે.
- **શોર્ટલિસ્ટ:** તમને ઇન્ટરવ્યુ માટે પસંદ કરવામાં આવ્યા છે.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. ડેશબોર્ડમાં "અરજી કરેલી નોકરીઓ" ટેબ પર ક્લિક કરો.
2. દરેક અરજીની વર્તમાન સ્થિતિ જુઓ.
3. ઇન્ટરવ્યુ સંદેશાઓ તપાસો.

### અપેક્ષિત પરિણામો
તમને તમારા તમામ પ્રયાસોનો સ્પષ્ટ રેકોર્ડ મળશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **કોઈ અપડેટ નથી** | નોકરીદાતાઓને સમીક્ષા કરવામાં થોડા દિવસો લાગી શકે છે. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** સારી તકો માટે 5-10 યોગ્ય નોકરીઓમાં અરજી કરો.
