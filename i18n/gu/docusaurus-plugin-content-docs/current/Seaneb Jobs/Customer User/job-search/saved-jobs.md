# સાચવેલી નોકરીઓ

તમારી મનપસંદ નોકરીઓને બુકમાર્ક કરો જેથી તમે પછીથી તેની સમીક્ષા કરી શકો અથવા અરજી કરી શકો.


![સાચવેલી નોકરીઓનું ડેશબોર્ડ](/img/web/savedjobs.png)


### સાચવેલી નોકરીઓનું સંચાલન
- કોઈપણ કાર્ડ પર બુકમાર્ક આઇકોન દબાવીને સાચવો.
- "સાચવેલી નોકરીઓ" ટેબમાં તમારી યાદી જુઓ.

### પૂર્વજરૂરિયાતો
- એક સક્રિય સીનેબ જોબ્સ એકાઉન્ટ.
- તમારા ફોન અથવા કમ્પ્યુટર પર સ્થિર ઇન્ટરનેટ કનેક્શન.

### પગલાંવાર માર્ગદર્શિકા
1. નોકરી પર "સાચવો" આઇકોન દબાવો.
2. ડેશબોર્ડમાં "સાચવેલી નોકરીઓ" ખોલો.
3. જ્યારે ઇચ્છો ત્યારે ત્યાંથી સીધી અરજી કરો.

### અપેક્ષિત પરિણામો
તમારી પસંદ કરેલી નોકરીઓ એક જગ્યાએ સુરક્ષિત રહેશે.

### સામાન્ય સમસ્યાઓ અને ઉકેલો
| સમસ્યા | ઉકેલ |
| :--- | :--- |
| **નોકરી યાદીમાંથી ગાયબ થઈ** | જો નોકરીદાતાએ ભરતી બંધ કરી હોય તો તે સમાપ્ત થઈ જાય છે. |

### ઉપયોગી ટીપ્સ
> **ટીપ:** સારી નોકરીઓમાં ઝડપથી અરજી કરો જેથી મોડું ન થાય.
