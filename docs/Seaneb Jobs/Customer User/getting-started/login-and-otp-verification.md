# Login & OTP Verification

Seaneb Jobs uses One-Time Password (OTP) verification for every login. This guarantees high security without requiring password resets or risk of stolen credentials.


![Seaneb Jobs Mobile Login Screen](/img/web/login.png)


![Verify OTP Screen](/img/web/otp.png)


### How OTP Verification Works
Each time you log in, our system generates a fresh, encrypted 6-digit code sent directly to your verified mobile number via SMS (and WhatsApp where enabled).

> **Security Warning:** Seaneb Jobs staff will **never** call or message you asking for your OTP. Never share your OTP with anyone, including recruiters or employers.

### Prerequisites
- An active Seaneb Jobs account.
- A stable internet connection on your phone or computer.

### Mobile App Experience

![Mobile View - Fast OTP Login Screen](/img/mobile/login.png)

### Step-by-Step Instructions
1. Click the "Login" button on the Seaneb Jobs homepage.
2. Type your registered 10-digit mobile phone number.
3. Click "Get OTP".
4. Read the 6-digit code received on your phone via SMS.
5. Type the 6 digits into the boxes on your screen. The system validates the code automatically upon typing the sixth digit.

### Expected Results
You are securely authenticated and your active session is maintained for up to 30 days on your device.

### Common Problems & Solutions
| Problem | Solution |
| :--- | :--- |
| **Invalid OTP error** | Make sure you are entering the most recent OTP received. If you clicked resend multiple times, only the latest code is valid. |
| **OTP expired** | OTPs are valid for 5 minutes. If time expires, click "Resend OTP". |

### Helpful Tips
> **Tip:** Do not log out on your personal mobile phone so you can quickly check application updates and notifications.
